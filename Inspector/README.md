# 検証用プログラム

## ボード

トグルが下の状態で左タクトを押すと１個目のセグの数値が減少し、右タクトを押すと２個目のセグの数値が減少する。  
トグルを上げると、２つ目のセグの小数点が点灯し、タクト押下時の減少が増加になる。  
半固定抵抗を調整すると、３つ目のセグの値が同期する。

## モーター

トグルスイッチを上げると、DCモーターとステッピングモーターが正転し続ける。  
更に右タクトを押すと、モーターが逆転し、DCモーターの速度が低速になる。  
DCモーターが３周する毎に、中音で0.3秒ブザーが鳴動する。

## ライト

何も押していない状態で赤、左だけ押すと青、右だけ押すと緑、両方押すと白になる。  
半固定抵抗で明るさを調整できる。
